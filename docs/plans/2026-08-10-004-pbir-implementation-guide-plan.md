# PBIR Implementation Guide Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add `docs/reference/pbir-guide.md` - a single self-contained "PBIR Implementation Guide" page for the 2.0 (`next`) docs, modelled on Deneb's guide (`C:\Repos\deneb-viz.github.io\docs\deeper-concepts\pbir-guide.md` - read it before writing prose), teaching PBIR authoring of HTML Content visuals via a quick reference, a six-stage build-up walkthrough, full property tables, and a property type guide.

**Architecture:** Approved design: [docs/plans/2026-08-10-003-pbir-implementation-guide-design.md](2026-08-10-003-pbir-implementation-guide-design.md). Two verification inputs feed the writing tasks: (1) property defaults/labels extracted from the visual source repo (`C:\Repos\powerbi-visuals-html-content`), and (2) per-stage `visual.json` files captured from a real report in Power BI Desktop - **no JSON sample in the page may be hand-written**. Capture artifacts live in untracked `working/pbir-guide/`. All doc edits land in `docs/` only; `versioned_docs/version-1.6/` is never touched. Single build gate at the end; commits are proposed to the maintainer for approval, never run unprompted (maintainer preference).

**Tech Stack:** Docusaurus 3.7 markdown; Power BI Desktop + the `reports:pbir-cli` / `pbi-desktop:connect-pbid` skills for capture; `npm run build` as the gate.

**Working state:** Branch `docs/pbir-implementation-guide` (already created; design spec is its first commit).
